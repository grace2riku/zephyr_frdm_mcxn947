# 学習に使用したAIモデルの記録

各段階のREADMEに「学習に使用したAIモデル」の表を置き、学習中に使ったモデルとバージョンを記録する。
段階0〜2には保存済みチャットの情報を確認して追記済み。段階3以降は、その段階へ着手してREADMEを作るときに同じ欄を追加する。

## 記録する項目

| 項目 | 記録方法 |
|---|---|
| 利用期間（JST） | そのモデルを使った期間。正確な期間が不明なら確認日と確認範囲を記載 |
| AIツール | Codex、ChatGPTなど、使用したツール名 |
| AIモデル（モデルID） | 画面・保存済みチャット・APIの応答などで確認した識別子をそのまま記録 |
| AIモデルバージョン | 確認できた版の表記と、取得できた場合は固定スナップショットID。取得できない部分は「未取得」 |
| 推論設定 | 確認できる場合はhighなどの値。モデルバージョンと区別して記録 |
| 確認根拠 | 確認日、画面やログの種類、対応するチャットIDなど |

モデルIDはモデルを識別する情報として扱う。[OpenAIのモデルIDの説明](https://developers.openai.com/api/reference/resources/models/methods/list)も参照。
たとえば`gpt-6.1-sol`では「6.1」はIDに含まれる表記として記録できるが、そこから固定スナップショットIDや内部のビルド番号を推測しない。
Codexアプリ自体のバージョンも、AIモデルバージョンとは別の情報である。

段階0〜2のモデルIDと推論設定は、各段階の保存済みチャットにある`turn_context.model`と`turn_context.effort`で確認した。
確認できた記録の範囲では、3段階とも`gpt-6.1-sol`／`high`。固定スナップショットIDは取得できていない。
チャット本文やログ全体はこのリポジトリにコピーしない。

## 後続の段階で使う欄

```markdown
## 学習に使用したAIモデル

| 利用期間（JST） | AIツール | AIモデル（モデルID） | AIモデルバージョン | 推論設定 | 確認根拠 |
|---|---|---|---|---|---|
| 未記録 | 未記録 | 未確認 | 未確認 | 未確認 | 未記録 |

記録方法は[AIモデルの記録方針](../../docs/ai-models.md)を参照。
```

学習の開始時に確認できる項目を記入する。途中でモデルや設定を変更したら、期間を分けて行を追加し、以前の記録も残す。
過去のモデルが確認できない場合は「未確認」と記載し、現在の設定で過去の欄を埋めない。
